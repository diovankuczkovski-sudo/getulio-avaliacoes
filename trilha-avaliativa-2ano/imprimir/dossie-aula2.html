Juros simples

J = C · i · t (C = capital, i = taxa por período em decimal, t = períodos). Montante M = C + J = C(1 + i·t).

5% = 0,05. Os juros são sempre os mesmos em cada período, então o crescimento é linear.

Juros compostos

M = C · (1 + i)ᵗ. Em cada período, os juros incidem sobre o montante do período anterior, então o crescimento é exponencial. Os juros são J = M − C.

Para não depender de calculadora, use o fator (1 + i)ᵗ da tabela:

taxa \ meses12345
2%1,021,04041,06121,08241,1041
3%1,031,06091,09271,12551,1593
4%1,041,08161,12491,16991,2167
5%1,051,10251,15761,21551,2763

Comparando e interpretando taxas

No 1º período, juros simples e compostos dão o mesmo valor. A partir do 2º, o composto é maior. Taxa implícita de um parcelamento: i = (valor a prazo − valor à vista) ÷ valor à vista.
